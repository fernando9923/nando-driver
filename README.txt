NANDO DRIVER - PWA untuk iPhone

Isi folder: index.html, sw.js, manifest.webmanifest, dan 3 ikon. Semuanya harus diunggah dalam satu folder yang sama.
URL Apps Script dan Firebase sudah tertanam di index.html.

CARA MEMASANG (pilih salah satu, keduanya gratis dan sudah HTTPS)
A. Netlify Drop: buka app.netlify.com/drop, seret folder ini ke halaman itu. Anda langsung mendapat alamat web.
B. GitHub Pages: buat repositori baru, unggah semua file, lalu Settings > Pages > pilih branch main.

DI IPHONE DRIVER
1. Buka alamatnya di Safari.
2. Tekan tombol Bagikan, lalu Tambahkan ke Layar Utama.
3. Buka dari ikon di layar utama, login, lalu izinkan lokasi saat diminta.

CATATAN
- Antrean offline terkirim saat aplikasi dibuka lagi atau begitu internet kembali selagi aplikasi terbuka.
- Posisi live hanya terkirim selama aplikasi terbuka dan layar menyala (layar dijaga tetap menyala).
